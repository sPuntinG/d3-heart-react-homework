Bundle = transform code so that the browser can run it. Reason: we can write React components using JSX (human readable), but the browser cannot read JSX -> bundling makes all these files browser-readable. Basically, everything needs to be transformed / translated to HTML, CSS, and JavaScript.

JavaScript (JS) = the programming language understood by the browser. 

Vite = one of the most popular frontend build tools. Vite can do the bundling.

Node.js = a JS runtime = allows to run JS outside of the browser, directly in a terminal.

npm = "Node Package Manager", a tool to install and manage JavaScript libraries ("packages"), like D3, React, ...
